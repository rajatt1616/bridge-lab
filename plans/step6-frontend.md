# Step 6 — Frontend Skeleton

- `index.html`: layout with header, toolbar, canvas, results side panel, footer.
- `css/styles.css`: theme variables, layout, responsive basics.
- `js/state.js`: mode state machine.
- `js/canvas.js`: grid drawing + joint/member rendering.
- `js/tools.js`: click to add joint, analyze button calls `/api/analyze`, reset.
- `js/api.js`: fetch wrappers.
- `js/main.js`: DOM ready hook.
